# 弈武

象棋走位与卡牌武斗结合的二维回合制游戏。当前版本为 **0.6.29 开发测试版**，欢迎试玩并反馈。

**[直接试玩](https://juncxio.github.io/yiwu/)** · **[提交试玩反馈](https://github.com/JunCxio/yiwu/issues/new?template=feedback.md)**

## 开始游玩

1. 初次游玩，建议在首页选择「分步教学」，学习克制、气势、撤回与支援。
2. 选择电脑对战或同机双人。电脑对战中，你执红方；可选练习或标准难度。
3. 选择快速对局、标准棋局或残局挑战，点击「开始游戏」。
4. 正式对局已准备好分散配牌，可直接开始，也可先调整。双方培养预算相同，每子最多学习两张牌。
5. 点击己方棋子和落点移动；交战时先看预览，再发起武斗。双方暗选招式，同时结算伤害。
6. 不清楚下一步时，可使用「提示一步」「选招建议」及其理由说明。

残局挑战显示当前关次。前两关成功后，可先复盘，再点击「下一关」并确认切换，沿用当前电脑难度；确认前取消或刷新仍保留原终局。最后一关成功后可返回首页选择其他棋局。各关仍可从首页单独选择，没有额外解锁或养成奖励。

残局交战前会核对指定主力、支援与保护棋子：用错棋子击败目标、缺少首关支援，或先击败黑将，都会明确提示风险。武斗窗口中的普通说明默认折叠，有风险时自动展开；选招时保留手动展开或收起的状态。说明只依据公开棋局和本场固定支援，不读取暗招，也不保证武斗获胜。

残局目标区显示剩余的双方棋盘行动；正在进行的整场武斗计一次。临近时限时，落点预览、整备确认和交战预览会说明本次行动的代价；最后一次行动仍可正常完成目标。交战预览也会提示临近无伤判和的风险，是否判和仍以本场实际结果为准。

点击「主动撤回」后先核对双方生命、耗尽牌、气势清零及下一方行动，确认后才结算。撤回会直接结束本局时，提前显示胜负或判和原因；残局还会显示撤回后的剩余行动。返回选招、按 Esc、回首页或刷新会取消未确认撤回，保留已选招式与已锁定暗招，不消耗行动。

手机武斗优先展示招式：待机角色缩成对峙栏，短屏选招时让出更多操作空间，揭示后恢复完整像素演出。点击「查看推演」后可用「返回选择招式」回到原选牌；跳转不会锁牌或结算。选招时的交锋记录放在推演之后，结果页仍可先查看记录。

培养牌不可用时，选招页与对手公开配牌会说明本场状态和具体条件，例如本兵尚未过河、哪方有几名支援，或守方不能使用借架。耗尽、满气势的原因优先显示。交战预览列出全部支援棋子的名称与路、线位置，支援输出最多加 2；支援在开战时固定，不能在武斗中调动。

交战预览新增「首轮判断」：列出可确保击倒目标并存活的招式，或提示守方能确保反杀的具体招式。判断使用双方当前全部合法招式，计入支援、克制、减伤和耗牌，不读取暗选，也不保证后续轮次的胜负。走棋建议使用相同说明；标准电脑会优先落实已确认的首轮存活击倒，练习电脑保留原有选招分布。

## 主要规则

- 保留象棋走法、阻挡、九宫和过河限制。不判将军或将死，将帅阵亡判负。
- 斩击克破势，破势克架势，架势克斩击。蓄势放弃本轮攻击，积累气势。
- 各类棋子基础生命和输出相同，培养用于学习招式，不增加基础数值。
- 站位可提供支援；伤势和培养牌消耗跨战斗保留。整备一张耗尽牌会占用一次行动，不回血。
- 武斗第二轮起，进攻方可在锁定招式前主动撤回，先核对代价再确认，保留伤势与消耗。
- 同一完整局面第三次出现，或连续 80 次棋盘行动没有损血，判和。棋盘显示判和进度；落点预览和整备确认会提醒该操作是否直接判和。
- 页面内「查看玩法」提供完整规则，伤害拆解说明各项加成和减伤。

武斗提供七类棋子的红黑像素角色，以及出招、受击、阵亡和撤回表现。双方锁定后才揭示动作，演出不改变伤害与出招顺序。刷新续局只显示静态结果。已揭示后可点击「重看出招」，撤回后可重看撤回；重看保持原有伤势、耗牌和回合。

交锋首轮揭示后即可展开「交锋记录」，查看双方每轮的实际损血、生命变化、气势和克制结果。最新轮次在前，累计损血只统计本场；记录不会显示尚未揭示的招式。

支持电脑对战及同机双人；当前没有联机对战。

## 续局与数据

最近一局自动保存在当前设备、浏览器和网站地址下。刷新后先进入首页，点击「继续本局」恢复。清除网站数据会删除续局，不支持跨设备同步。本机开发地址的续局不会自动转移到此试玩地址。

游戏不收集或上传对局数据。若浏览器无法保存，会在页面中提示；请确认保存状态后再关闭页面。

遇到问题可在首页续局区、棋盘顶部或武斗窗口点击「导出试玩记录」，下载本局 JSON 文件。文件包含版本、模式、配牌与已执行操作，不包含尚未揭示的暗招、账号信息或其他网站数据，不会自动上传。导出不消耗行动，也不会改变电脑已锁定的招式。当前文件用于排查问题，不支持导入续局。

## 已知问题与反馈

电脑已改进重复追将与可确定的首轮交战评分，仍可能出现长局。集中培养、分散培养和不同卡牌组合已做自动对照；这些结果不能保证真人对局的整体平衡，具体范围见测试文档。

请通过反馈入口说明关键操作、实际结果与预期结果，并附上导出的试玩记录。若无法附加 JSON 文件，可将文件内容粘贴到代码块中。截图和大致对局时长也有帮助。

## 本地运行

本项目无需构建或后台服务，入口为 `index.html`。下载后可直接用浏览器打开；保存能力取决于浏览器。也可在此目录启动任意静态文件服务器，例如已安装 Python 时运行：

```sh
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。

已安装 Node.js 时，可运行 `node tests/computer-opening.cjs` 检查首轮判断及电脑决策，运行 `node tests/combat-help.cjs` 检查配牌条件与支援说明，运行 `node tests/challenge-flow.cjs` 检查残局目标、行动后果、切换与续局，均不需要安装依赖。
