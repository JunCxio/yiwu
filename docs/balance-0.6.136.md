# 0.6.136 现版培养平衡核查

现版五类培养方案完成1,072场测试，358,648条操作全部按真实规则重放。没有单子造成全部实际损血的胜局，也没有方案在同一组对四类对手均超过半分，因此未触发开跑前规定的追加复测。兵卒优先集中在快速局表现较强，但没有通吃；高和棋比例、长局及样本关联仍限制结论，不能宣称培养已经平衡。

本轮发布核查资料，游戏保持0.6.136。取样基线提交为 `ceb2160208e963021b58f151706882057c465c36`，入口及本机镜像SHA256为 `812c41ee1b1edbe63fb2b930ec1593ca89123b65edfb816131fa2ddd40e4fe16`。规则、电脑策略、培养数值、页面与续局格式没有修改。

[完整冻结计划、配牌、操作、逐子统计、分析方法及源码快照](data/balance-0.6.136.json.gz)为gzip压缩JSON，SHA256为 `0657d66ea8a206f34500536e66d83299d89fdd2df831b8a3775e6ca949237270`。[独立复核脚本](data/verify-balance-0.6.136.cjs)只使用Node.js内置模块。

## 方法与范围

标准、练习两种电脑各在快速、完整棋局中测试默认、分散、车马炮优先集中、兵卒优先集中与混合集中。双方预算相同且用完，初始生命18、每子最多两牌。默认及分散给快速6子或完整12子各一牌；集中给快速3子或完整6子各两牌。兵卒优先集中也可能培养士象；它是培养顺序，不代表只用兵卒。具体棋子与卡牌见plan.allocations。

每对方案使用三个变体的全部交叉，默认只用变体0；每对取两组成对随机起点，再交换红黑，随机序列跟随方案。每难度每棋局264场交叉、4场默认对默认的随机流交换控制，共1,072场、264个变体组、52份配牌、88组成对随机起点、176个不同种子。变体共享随机根，1,072场不是1,072个独立样本，也没有穷举全部合法配牌。

种子标签为 `yiwu-balance-matrix-0.6.136:20261113:current`，明确排除前一份对手回应试验计划的6,492个已记录值。这个范围不是全项目历史的穷尽排重。前置核查验证等预算、两牌上限、红黑旋转、5,632个随机前缀值，并精确复现四份现版控制的完整电脑选择、命令、逐子统计和终态。两原进程正常退出，无重复、遗漏或失败场；2,000次行动、14,000条命令只作失败保护，不能用于指定和棋。本批全部按规则自然结束。

标准／快速有9场仅一子主动开战，来自3组方案对随机根、7条不同的配牌后操作序列。其他棋子通过反击每场实际造成16～36点损血。

练习／快速有21场仅一子主动开战，来自5组方案对随机根、8条不同的配牌后操作序列。其他棋子通过反击每场实际造成17～30点损血。

“只有一个棋子主动开战”不能解释为其他棋子没有贡献。角色记录分别保留主动伤害、防守反击、承伤、合法支援与友方炮架。支援名单记录全部合法来源，实际加成最多2点；这里核查参与关系，没有通过移除某个棋子测量其因果贡献。

标准／快速：连续 80 次行动未造成伤害 162场；同一完整局面第三次出现 11场；双方将帅同时阵亡 3场。

标准／完整：连续 80 次行动未造成伤害 188场；同一完整局面第三次出现 5场。

练习／快速：连续 80 次行动未造成伤害 135场；同一完整局面第三次出现 4场；双方将帅同时阵亡 2场。

练习／完整：连续 80 次行动未造成伤害 189场；同一完整局面第三次出现 2场；双方将帅同时阵亡 2场。

全部交叉对局均发生过交战和实际损血；连续80次无伤判和也全部发生在此前已经造成伤害的对局中。最长697次行动，最后一次损血为第617次行动，随后按80次无伤规则判和。这说明尾局停滞仍需处理，不能把本轮“没有单子全部输出胜局”当作玩法或节奏问题已解决。

## 追加条件与独立复核

主批开跑前固定两类追加条件：某方案对其余四类均超过半分，每个对手取18个新根并换色，共144场；单子全部输出胜局则按固定双方配牌单位去重，每单位取18个新根并换色，共36场。主批没有触发，confirm-plan保留空输入、空单位和6,668个排除值，本轮追加测试为0场。未启动额外进程，空确认报告不代表已经做过新随机根确认。

在仓库目录运行：

```sh
node docs/data/verify-balance-0.6.136.cjs
```

后续入口改变时，可从上述基线提交取出index.html，作为第二参数传入；压缩数据也保留sourceText源码快照。复核脚本独立生成计划、配牌及种子，重放全部358,648条操作，核对实际损血、逐子活动、支援名单、炮架、完整终态、方案对手统计、颜色和节奏，并重新核对追加条件。

它额外重算四份旧控制及主批四组最长局，共8场、3,785条操作、3,161次棋盘选择和901次武斗选择，均与记录一致。抽查方法在读取分组结果前写入verification-method，不宣称已独立重算全部1,072场电脑选择。传入错误源码、篡改损血和删除对局时，复核脚本均正确拒绝。

## 后续与限制

本批不支持直接削弱某张牌，也不能证明集中培养风险消失。下一步优先研究无伤尾局与重复调位，并对兵卒优先集中保留观察。本轮未开展规则数值试验。

本轮没有改游戏入口，没有重复不受影响的界面、旧规则回归、续局或性能测试。没有完成全部合法配牌、人类策略、独立先后手复测、真人或实体手机验证。现版仍为开发测试版。
