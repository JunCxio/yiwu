# 0.6.133 交战前的解围提示

己方将帅已经受攻时，普通棋子发起反击尚未改变棋盘站位。原界面会说明首轮吃子机会、支援与双方生命，但没有直接列出当前仍能进攻将帅的棋子，容易把预计交战收益理解为已经解围。

现在交战预览与走棋建议共同显示「解围尚未确认」，列出来袭棋子的名称、位置及己方将帅，并说明撤回或六轮未分胜负后仍需检查防线。提示只使用公开站位，不读取本轮暗招；能进攻将帅也不等于能击倒将帅。

仅在普通棋子进攻、没有可确保存活的首轮吃子招式、当前己方将帅受攻时显示。首轮可靠吃子继续使用原有战后漏防判断；将帅亲自交战、已经进入武斗、残局挑战与当前未受攻的局面不叠加这条提示。
