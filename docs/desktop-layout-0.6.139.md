# 0.6.139 桌面对局布局

普通对局点击「提示一步」后，右侧的建议、棋子说明和战局记录会把整页撑长。Edge在1366×768窗口的快速局中，原版页面约1,690像素高，右侧详情约1,438像素，左侧约833像素，查看棋盘和说明需要反复滚动整页。

## 修改范围

宽度至少1,101、高度至少650像素时，普通配牌和对局两侧面板的高度随窗口限制，正文在面板内滚动；保留原有可聚焦面板及焦点框。棋盘按可用高度缩放，棋子字号根据棋盘宽度计算，避免小棋盘仍使用大窗口字号。

终局结果出现、教学指引可见或残局目标可见时，不启用本次紧凑布局。窄屏和更矮窗口沿用原样式。没有强制整页固定高度，没有隐藏说明和控件；落点风险等较长内容仍允许整页滚动。

规则脚本、电脑脚本逐字节保持。界面脚本只同步试玩记录的版本字符串，存档格式仍为1，续局仍通过已执行命令重建。没有调整伤害、培养、判和或电脑评分。

## 验证

- 143项既有界面流程全部通过，未修改旧断言。
- 1366×768快速局，完成配牌并打开提示后，文档高度为858像素，两侧面板为568像素。右侧约1,477像素正文可在面板内访问；键盘End可到达末尾，Home可返回顶部。
- 棋盘外框为390像素宽；约31.88像素的棋子使用22.75像素文字。首版隔离候选仍用31像素文字，检查后修正，未发布该候选。
- 取消移动预览后棋子和回合保持；确认移动后红炮到达5路3线，电脑正常回应；刷新后从首页继续到第2回合，红炮位置及两次行动记录保持。
- 另核对1,101×650和1,920×1,080桌面配牌；320×740继续自然滚动，没有横向溢出。
- 教学、残局目标及通过4次真实行动产生的挑战失败结果页，两侧面板计算样式仍为不限高、自然展开。
- 所测Edge页面无控制台警告或错误。

复现：将窗口设为1366×768，在首页选择默认「快速对局 · 各8子」和「练习电脑」，依次开始游戏、完成配牌、提示一步。用Tab进入两侧面板，用Home、End或方向键查看内容。开启落点预览后，可取消或确认红炮向5路3线的移动，再刷新并继续本局。

## 限制

本次仅改善布局，不证明电脑更强、培养更平衡或长局已经解决。未重复完整引擎和平衡回归，未做实体手机、其他浏览器及旧浏览器兼容性测试。高度不足650像素时保留自然滚动；较长预览仍可能超过一屏。容器字号采用现代浏览器的容器查询单位。
