# 0.6.96 反威胁与将帅避险估值

原走棋评分可能把需要等到下一回合才能兑现的攻将收益，用来抵销己方将帅当前受到的进攻。例如黑炮移开防线后虽然能进攻红帅，但下一步轮到红方，红车已能先攻黑将。现在只在普通棋局、己方将帅仍有实际受攻风险且轮到敌方行动时，降低这类待兑现的攻将收益。没有己方将帅危险时，保留原有主动进攻价值。

该修正复用现有将帅风险与低权重，不新增数值参数；可确保反杀的进攻仍沿用原过滤。共享走棋评分用于练习电脑、标准电脑和「提示一步」。确定胜局、武斗暗选、伤害、卡牌、默认配牌、页面样式及续局格式保持不变。这仍是站位估值，不是更长的走棋搜索，也不保证替代行动能赢。

[原始输入、全部指令、终局哈希、实际伤害、冻结源码与验证结果](data/counter-threat-0.6.96.json)同时保留采用和未采用的两个候选。测试基线为正式 0.6.95，提交为 `96fcb64ad7533009d7bf82f1849c8eafa62f2e79`；正式 0.6.96 的电脑逻辑与采用候选一致，另补一处估值限制注释和版本信息。
