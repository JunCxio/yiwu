# 0.6.107 普通残血目标的两轮吃子判断

一份标准局在第329次行动时，红仕能在两轮内存活吃掉3血黑马，并解除原有受攻。原版只识别普通目标的首轮可靠终结，其余交战主要按平均伤害估算，因而选择继续移帅。本版为这类普通残血目标补充两轮真实结算，电脑与提示共用结果。

## 实现范围

首轮只搜索至多3血的普通目标，后续轮只搜索至多2血；双方都不能是将帅，排除残局挑战。每次搜索最多当前和下一轮，也不超过武斗第六轮。每个进攻招式枚举全部公开合法回应，后续可根据已经揭示的新状态重新选招，要求进攻子存活、目标阵亡；若本轮已有可靠终结，优先兑现。

实际终局按真实胜负或和局评分，排除敌方获胜。非终局检查吃子后的真实站位，不增加当前将帅受攻程度，也排除对手下一次行动在武斗前两轮内确定取将的分支。递归中的当前风险重新计算。这个范围不等于穷举其他棋子救援、完整武斗或更长序列，吃子也不代表整局获胜。

走棋在未找到可靠首轮终结时，使用可靠两轮方案最差回应的真实站位分数。标准电脑武斗仍先执行原防守过滤，再筛选保留下来的可靠吃子方案，之后共同经过省牌与概率归一；没有新增绕开省牌流程的提前返回。练习电脑武斗出招分布不变，但两种难度共用的走棋排序会改变。

交战预览、走棋理由、选招建议与电脑说明同步说明所需首招、下一轮重选及后续风险。规则、培养牌数值、CSS、续局版本与格式保持不变，现有记录可继续按实际规则重放；导出游戏版本更新为0.6.107。

## 病例与回归

第329步完整合法历史及红黑旋转均改为推荐仕吃马；原版在具体棋盘排序断言失败，并非因为缺少新增接口而失败。实际选招共56条回应分支全部兑现两轮存活吃子。另以六类普通棋子构造576个局面，其中180个有可靠机会，1,906次实际策略结算核对存活、吃子、将帅防线和输入不变。还覆盖目标生命、濒死进攻子、第六轮、残局排除与不读取暗招。

全部36个仓库脚本、31项规则、143项界面流程通过。关联预览回归覆盖刷新与取消不执行。旧两轮胜局测试的普通目标构造误删了敌将，现补回真实敌将，保留吃普通子不等于整局获胜的断言。省牌回归不再绑定旧版选招概率，改与同版禁用省牌时的计划比较实际概率转移；保留原合法历史、逐回应等效结算和重复风险检查，并增加第六轮有价值牌仍保留的例子。该项另覆盖1,152个输入、18,816条真实结算分支及48次正概率转移。

正式新增回归可运行：

```text
node tests/computer-two-round-capture.cjs
```

## 完整对照与限制

基线是提交 `62a055f1bf0a12aea77c8f575f2ec9adedd4ead2` 的0.6.106。运行前冻结最终源码、输入计划、驱动及上限：2,000次棋盘行动或14,000个内部步骤未自然结束时报错，不把测试上限算作和棋。最初候选另有试跑；它不计入以下最终验证，最终新种子也排除了其种子。

12份旧病例各跑基线与候选，共24场；全部基线的完整命令、逐子统计和终局哈希精确复现。旧快速481步、498步和棋分别变为401步、312步和棋，旧标准590步和棋变为242步和棋。另一份134步黑胜变为181步和棋、129步红胜变为104步黑胜、另一份134步黑胜变为143步红胜，变化并非全都更好。旧黑车单子输出36步胜局仍精确复现，不能称为解决单子主导。整局可能更早分叉，不能把所有变化归因于第329步。

另两场只用0.6.106的单步诊断中，原查询仍消耗随机输入，只替换第329步；此前命令前缀一致，590步和棋变为427步和棋。两场共1,253条指令独立核对，只是同一旧根病例，不计作新平衡样本。
