# 0.6.131 主动交战解围的完整分支核查

此前[练习快速局诊断](home-difficulty-0.6.130.md)检查了安全空位移动、整备及守将出招，未覆盖友军主动交战解围。本轮补齐这一范围：在25份单子实际输出胜局记录的33个末次行动入口，枚举全部61种主动交战替代，再将每个替代按原练习策略续跑至自然终局。

替代后原败方取得9胜、17和、35负，但战后立即解除将帅威胁的只有4个。对这4个入口追加256场条件随机对照，反击效果有好有坏，不能据此统一提高进攻权重。本轮没有修改游戏HTML、电脑策略、卡牌、伤害、布局或存档格式，版本仍为0.6.131。

## 固定入口与方法

来源为[0.6.129培养核查](balance-0.6.129.md)主批12份、追加复测13份单子实际输出胜局记录。多份配牌记录共享随机根及操作序列，同一对局的不同被进攻时点也相关；25份记录和33个状态不能当作独立总体抽样。当前0.6.131的规则与电脑脚本同上述来源逐字相同，入口源码固定在提交 `e73f11a5db8221faa3648fcf57521b072baa209f`，SHA256为 `824a99857d3cafe56bfe14893e995543f1e69fd7b71050e3eb7c2d39e3d0644b`。

逐条重放真实前缀并重算电脑选择，核对每个入口的完整状态与双方随机状态。对全部合法主动交战的首招及守方回应调用真实结算，共1,289次。安全解围要求本轮已结束交战、己方未判负，且将帅没有仍可进攻且无法保证反杀的敌子；继续交战的分支不能算已解围。没有发现一轮保证解围招式，现有两轮保证吃子查询也未命中；后者不等于穷举所有两轮救援策略。

随后在每个入口保留原控制，并为全部主动交战各建一个分支，共94场。强制替代前先消费原走棋的一次随机选择，双方之后均用原练习策略和各自随机状态自然续跑。资源上限为2,000次棋盘行动、14,000个执行步骤，触顶报错而不记和局。本批全部自然结束，33个原控制的全部操作和终态与旧记录一致。

## 四个入口的条件随机对照

四个入口来自上述实际解围结果，属于事后筛选。对每个入口固定原走法和反击两种行动，各使用32对新后续随机状态；两种行动先消费一次原走棋的随机选择，之后仍按原练习策略自然续跑。共256场、128组随机状态、256个种子，与5,276个明确旧值排重。没有从新开局抽样，也没有做完整的红黑换色复测。
