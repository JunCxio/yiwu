# 0.6.105 普通交战的开战前防守检查

电脑原先对移动和整备检查将帅空位退路及对手下一手的协同逼帅；普通交战没有可靠首轮终结时，只在平均伤害预估的战后站位中检查新增直接受攻，漏掉了后一种风险。进攻因此可能被高估，虽然尚未立即受攻，将帅仅有的退路却能被对手调马建炮架封住。

本版将原有的退路与协同逼帅代价提取为共享函数。普通交战继续沿用平均伤害估计，按预估损血、占位、存活棋子及交给对手行动的状态，比较新增直接威胁和新增退路风险。原权重保留，不奖励尚未确定的解围收益；可靠首轮终结仍按真实结算评分，整局确定获胜仍优先。

这是评分漏项修正，不是完整武斗或将死搜索。平均伤害、预计阵亡及占位可能与实际暗选招式不同；检查至多一条安全空位退路被下一手协同进攻封住的情况，没有穷举其他棋子的完整救援。提示说明同步标明这一估计范围。

## 完整合法病例

上一轮已公开的快速局第20次行动前，黑将在 `(5,0)`，只有 `(5,1)` 一条安全空位退路。旧版选择黑炮从 `(4,0)` 进攻红兵 `(4,6)`，评分约−0.275，比先移黑将到 `(5,1)` 的−0.418高。

实际四轮后黑炮18→4血、红兵18→7血，黑炮主动撤回。随后红马到 `(5,4)` 建立炮架，红炮能进攻黑将，也能覆盖其唯一空位退路。原局最终由红马在第25次行动取将。预估战后站位和实际战后站位均存在这条协同逼帅分支，但它不等于下一手确定败局。

新版在同一站位将该交战评分降至约−4.475，移将评分不变，推荐并实际选择先移将。红黑旋转、两种走棋难度及不同抽样输入结果一致。该病例整局从开局使用新版时，黑负25步变为黑胜38步；另一份旧病例黑胜102步变为黑胜38步。这些整局变化不能当作单次移将的独立效果。

- Edge 156在桌面实际选择黑将由6路10线到6路9线；标准与练习提示均推荐同一移将，没有执行行动。三次刷新核对90格棋位、生命与未耗牌数量一致，390×844无横向溢出，无控制台警告或错误。核对棋位时排除了“建议落点”这一临时提示标签。

回归可运行 `node tests/computer-attack-pressure.cjs`。测试使用独立临时端口，没有替换原站续局。

## 整局对照

基线为提交 `f17d982010eb3201191e550467a91aa316ed1130` 的0.6.104。运行前冻结两份源码、输入计划和驱动哈希。十份旧病例各运行基线与新版，共20场；基线控制的完整操作、逐子统计和终局哈希均精确复现。它们包含前轮七份病例与最新矩阵三条单炮输出序列，不是十个独立随机根。

新起点分两批，每批每模式四组随机序列对，涵盖默认对默认、分散对兵卒集中、车马炮集中对分散、混合集中对兵卒集中及所列变体。每组分别运行原版双方、新版执红、新版执黑、新版双方四场。共64场、16组序列对、32个不同种子，与已核对的720个旧种子无重合。同组四场共享随机根，不能视为64个独立起点，也不是完整培养交叉矩阵。

全部84场、24,994条指令按规则独立重放，预算、两牌上限、逐子实际损血、耗牌、阵亡、终局原因与哈希一致，均自然结束；没有把触及测试上限的对局记作和棋。
