现版完成1,072场培养配牌交叉与默认控制测试。主批练习电脑快速局出现12场单子实际输出胜局，完整局车马炮集中对四类对手都超过半分；按开跑前方法追加576场新随机根复核。单子胜局与集中方案优势需分别诊断，不能据此直接削牌或宣称平衡。长局和高和棋比例仍是后续重点，详细数据如下。

## 方法

标准、练习两种电脑难度分别在快速局和完整棋局中测试默认、分散、车马炮集中、兵卒集中、混合集中五类方案。双方预算相同且用完，每子最多两牌、初始18血；分散给快速6子或完整12子各一牌，集中给快速3子或完整6子各两牌。兵卒集中按兵卒、士象优先，混合按棋种轮换；具体名单见各组allocations，没有穷举全部合法配牌。

每对方案使用所列三种配牌变体的全部交叉（默认仅一种），每对两组随机根、交换红黑，随机序列跟随方案换色。每难度每棋局264场交叉与4场默认控制，共1,072场；264个变体组、52份独立配牌、88组成对随机起点、176个不同种子。变体共享根，不能把1,072场当作独立样本。标签为 `yiwu-balance-matrix-0.6.129:20261113`，与明确记录的4,524个历史或预留种子无重合；该集合包含0.6.113矩阵88个种子，不代表全项目历史穷尽。

前置核查包含预算、两牌上限、红黑旋转、5,632个随机前缀值，以及四份旧版同策略对局的完整精确复现。初稿驱动遗漏守方难度参数，已由旧控制抓出并在主批开跑前修正，输入、原断言与游戏源码保持。四个原进程各完成268个固定输入且正常退出，无错误、重复或遗漏。上限2,000次棋盘行动、14,000次内部步骤；超限即报错，不记为和棋，本批全部自然终局。

## 新随机根独立复核

按主批开跑前固定的diagnostic-method，每个单子案例的配牌单位取18个新随机根并交换红黑：12个单位共432场。通吃方案另对四类对手各18个新根并交换红黑，共144场；每根只取一个均衡轮转的变体组合，18根覆盖九种非默认双变体组合各两次。总计576场、288组成对随机起点、576个新种子，与主批及4,524个明确历史或预留值排重（联合4,700值），不重复使用主批随机根。

432场单子配牌复核中，出现13场单子实际输出胜局。全部576场的角色重放另检出13场，具体配牌、胜方、主力培养及支援见diagnostics.supportAudit.rows。这13场来自12组方案对随机根，15～57次行动结束，获胜方仅输出棋子为车、马或炮，实际损血18～36点；1场主力未培养、4场没有使用培养牌，另2场有友方炮架。主批12场其实来自2组方案对随机根、2条配牌后操作序列：3场黑车只学一张牌，9场红炮未培养且未耗牌，均只造成18点实际损血并直接击倒将帅，没有扫清对方全军。9场红炮胜局另有友军充当炮架。这些案例显示练习对弈中可出现早期直接取将，不能归因为最强双牌主力碾压，也不能断言集中培养风险已消除。

## 复核与限制

在仓库目录运行：

```sh
node docs/data/verify-balance-0.6.129.cjs
```

后续版本可从上述Git提交取出index.html，作为第二参数传入。脚本独立生成计划、配牌、真实规则重放与实际损血，并核对逐子活动、合法支援来源、角色分类、完整终局哈希、方案与对手统计、先后手和节奏。主批共370,592条命令，追加复测183,592条命令通过。它另重算四份旧控制及主批、追加复测各组最长局，共10场、5,192条命令、4,275次棋盘选择与1,389次出招选择；没有独立重算全部1,648场的电脑选择。传入错误版本源码及篡改逐子损血数据时均被拒绝。

本轮没有修改游戏源码，也没有重复不受影响的界面、规则回归、浏览器或性能测试。未完成全部合法配牌、人类策略、独立先后手复测、真人或实体手机验证。培养协同、长局和高和棋比例仍需继续优化。
