# 0.6.129 短屏武斗确认导航

短屏自然滚动时，选招推演与底部生命预测、锁定按钮之间还隔着公开配牌等内容。现在在已选招的推演末尾增加“前往确认”，滚动整个确认区，并将焦点放到原有锁定按钮。点击导航不会锁定或结算；玩家仍可返回推演、更换招式，再明确锁定。

## 适用范围

导航只在原有自然滚动条件下显示：窗口高度不超过500像素，或宽度不超过760像素且高度不超过700像素。普通桌面尺寸保持原显示，正文布局、自然滚动、交接隐藏及教学指引保留。尚未选招、交接、揭示结果和教学中不增加此入口。

复用现有武斗导航分支和按钮样式，没有增加持久状态、计时器或招式逻辑。全部规则与电脑策略脚本和0.6.128逐字相同，存档格式1及导出记录结构保持。本轮不包含平衡数值或电脑策略调整。

## 验证

- 旧版先在缺少确认导航的专项断言失败。新增[专项脚本](../tests/combat-confirm-navigation.cjs)4组，覆盖连续导航不改变棋局和存档、不读取或重抽暗招、仅明确锁定才结算、同机双方、交接隐藏、教学排除和按钮不可用时不移动焦点。
- 50个既有检查脚本原样通过，包含143项界面流程；没有改动旧断言。规则及电脑脚本逐字相同，没有用新完整对局矩阵支持平衡性结论。
- Edge使用独立本机来源和临时浏览器配置，检查1366×768、1024×640、390×844、390×640、320×568、760×480、900×480，各自电脑/同机模式，共14个流程和21次红黑选招状态。按媒体条件显示导航，新按钮至少44像素高；导航后生命预测与锁定按钮位于弹窗内，焦点落在锁定按钮，导航本身不改变保存记录。
- 每份待选状态刷新后恢复待选招式、电脑已锁定招式或同机先手暗选。显式锁定后按真实规则核对状态，只结算一次；结果刷新保留命令。没有页面错误或横向溢出。已查看320像素窄屏及760、900像素横屏截图。

首份候选在760×480中只滚动锁定按钮，生命预测仍可能被截掉，因此改为滚动整个确认区，再聚焦按钮。修订前源码及失败记录保留；没有放宽原可见性要求。测试中另修正了同机模式禁用电脑难度时的设置顺序，并在读取本机存档前等待异步保存完成，验收断言保持。

最终0.6.129入口再次完成上述14个导航流程，并另完成1366×768、390×844、320×568 × 两份旧三轮取将历史 × 新建议/旧待选，共12个旧续局流程。六份旧手动待选及电脑已锁定招式保留，六份新建议按真实结算在三轮内获胜；刷新不重复扣血。最终入口合计26个浏览器流程。
