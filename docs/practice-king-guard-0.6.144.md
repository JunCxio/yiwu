# 0.6.144 练习将帅避险

练习电脑此前按全部可用招式类型随机选择，即使将帅有完整的本轮安全应招，也会给立即败局的招式分配概率。真实合法记录中，黑将3血对红帅1血时，蓄势会在红方斩击下直接落败，而其他应招能避开本轮判负。

本版在普通对局将帅直接参与武斗时，使用公开局面逐一核对本轮全部合法回应；若存在不会本轮判负的招式，先排除危险招，再按剩余招式类型等概率选择，并从该类型中等概率选招。不会本轮判负包含双方同归于尽判和，不等于保证将帅存活，也不推断之后的回合。

没有完整安全招时仍使用原随机计划。普通棋子、残局、标准电脑、棋盘评分、练习电脑原有主动撤回优先逻辑保持。不读取玩家暗招，也不按出招历史反制。伤害、生命、培养预算、武斗六轮上限及重复、无伤判和规则均未改。

旧续局中已锁定的招式即使现在会被过滤，也按原决定揭示；刷新不重抽。揭示后写明沿用已锁定招式，不把旧决定归因于新策略。揭示前继续隐藏电脑决定。

## 证据与采用范围

初始核查重放34份旧单子输出胜局，败方将帅共197份交战状态。7份存在完整安全替代，而原计划仍保留危险概率；其中1份实际选择危险招并当轮落败。该例改用新计划后，从第29次行动红胜变为第31次行动红胜：避免了这一轮冒险，没有挽救整局。

隔离试验事前固定32组随机流、64个新种子，和已记录的8,502个种子排重。每组包含原版自弈、候选自弈及候选分别执红、黑对原版，快速与完整棋局各自覆盖五种既有培养风格。先运行64场主批，通过后才运行预留64场确认批。采用条件是各组直接得分至少8／16、自弈平均行动最多增加10%、每组8场自弈至多多1场和棋，用于容纳避免过早败局的代价。
