# 0.6.138 车炮走法查询

车、炮枚举落点时，原实现对同一直线的每个候选重新检查沿途阻挡。现改为四个方向各扫描一次：车在第一枚棋子处停止；炮在炮架前可走空位，遇第二枚棋子时仅允许交战敌子。结果仍按纵坐标、横坐标排序，因此同分走法及随机候选顺序保持。

修改位于共享规则的`moves`入口，棋盘标记、电脑决策、退路检查与提示均使用同一结果。`canMove`与实际移动的合法性校验保持，规则、评分、培养、判和、样式及格式1续局代码未改。页脚、试玩记录版本与导出文件名同步为0.6.138。

## 正确性

8,151组既有检查逐格比较合法落点、顺序、吃子标记和输入不变，覆盖各子各交点、友军与敌军阻挡、炮架及飞将。在完整战后评分的115次交战核查中，新增302,186次原版走法对照；87,099个评分终态、24份排名、异常与嵌套缓存恢复、724个历史反例终态均保持。该评分器仍是隔离候选，没有进入本版。

最终发布入口的58个既有仓库脚本及143项界面流程共59个任务通过，旧检查文件哈希保持，三段脚本可解析，入口与本机镜像一致。Edge使用隔离来源恢复第46次行动旧局，核对车的8个落点和4个交战目标、移动预览与取消、交战预览与取消，确认一次移动后刷新继续，位置与记录保持；未触碰正式站续局，未发现页面警告或错误。

## 性能

Node.js v24.21.0串行、无采样、预热3次、交替10次；沿用24处真实查询、4份旧长局快照及2份开局。每次核对完整排名与输入。原预算为中位不超过50毫秒、热单次及冷查询不超过100毫秒，开局中位额外耗时不超过5毫秒。30处全部通过，最高中位35.31、热单次37.55、冷查询41.33毫秒。

30处中位耗时合计313.304→292.824毫秒，约下降6.5%；这是这些固定样本的汇总，不能代替所有场景的帧耗时。Edge156另在6处复杂查询及2份开局同场交替计时，全部通过预算，排名与输入保持。

## 尚未采用的战后评分

新采样针对真正的精确战后排名，96次查询、576次预测。固定数组累计终态保持全部结果，但24处仍有6处超过预算，未显示稳定收益，舍弃此版。

原选择性历史分类预测器配合本次车炮扫描后，完整24处中19处通过，失败编号2、12、14、18、20，中位约55.70、59.89、50.60、56.71、52.20毫秒。因此精确战后评分继续隔离，没有启动整局采用对照，没有修改牌值或其他规则数值。不同批次的计时不能当作配对提速证据。
