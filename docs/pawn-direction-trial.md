# 兵卒目标方向试验

2026-11-11，以正式 0.6.87 为基线检查兵卒的接近评分。两个候选均未采用；本次只保存试验结论，游戏入口、本机镜像、规则、界面、电脑策略和续局格式没有修改。

## 问题与两个候选

现有站位评分按曼哈顿距离接近最近的敌子，没有区分兵卒能否后退。快速局种子 1469105、分散培养方案 1、方案方执黑的历史长局中，红兵到达底线后，仍可能因横向接近身后敌子而获得加分。这是一个静态评分差异，尚不能据此认定排除身后目标就能改善整局决策：敌子也会移动，走棋评分同时包含双方站位、威胁与重复局面。

两个候选都仅在兵卒的目标列表中排除身后的敌子：红兵保留 `q.y <= p.y`，黑卒保留 `q.y >= p.y`。车、马、炮仍使用全部敌子。

- 候选一：只有目标列表非空时，才增加接近、中央位置和推进分。该方案同时取消了无前方目标时原有的中央位置与推进分，修改范围较大。
- 候选二：保留原有中央位置和推进分；没有目标时，仅令接近分为零。接近距离为空时取 9，对应 `.07 * (9 - distance)` 为零。

这两种筛选都不是完整路径搜索；保留的目标仍可能受阻，不能称为全部实际可达。

## 新种子配对对照

快速使用 1569101–1569104，标准使用 1579101–1579104；每个种子交换方案方红黑，共 16 个配置。前两个种子采用默认配牌，后两个依次采用分散和混合方案，变体为种子偏移量除以三的余数；对手均采用默认配牌。双方预算相同，随机序列独立。
