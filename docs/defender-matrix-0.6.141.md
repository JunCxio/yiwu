# 0.6.141 守方合法应招

标准电脑此前在计算守方策略时，也会按进攻方将帅的战后风险排除部分攻击。这会假定玩家不会使用某些仍然合法的招式。例如，红仕进攻残血黑卒时，原守方几乎只防蓄势，面对合法斩击容易失子。

本版只调整标准武斗守方：比较对方全部合法招式；普通进攻子的每一种真实离场结果，若能让守方在下一次棋盘行动中、通过最多三轮武斗确定取将，则计入该机会。这样既能防守玩家的合法攻击，也保留合理弃子。其余组合继续使用既有本轮收益，仍有短历史应招和省牌判断，并非完整六轮搜索。标准进攻方、练习按可用招式类型等概率选择的约定、走棋评分、规则、培养、CSS及格式1续局保持。电脑选招说明和建议的判断范围同步更新。

## 正确性与影响范围

完整重放既有1,072份记录、358,648条操作，终态哈希均保持。在63,873个武斗状态查询标准守方，255处分布改变，其中36处不属于上一轮发现的219处。旧路径包含练习出招，不能把这些查询当作新版标准自弈。

全部255处及红黑旋转共510份矩阵，用真实结算和独立三轮取将搜索核对11,338个单元，其中2,584个单元有确定反击证明。标准进攻方与双方练习计划保持，概率合法归一，输入不变，异常和嵌套查询不污染后续调用。

计入已证明取将补偿后，最坏无补偿阵亡概率在44处降低、14处提高、197处保持。不能把局部存活率当作整体强度。固定反例同时包含：

- 记录450、第243条命令前，红仕18血进攻黑卒4血。最坏即时阵亡概率约99.875%降为61.36%；没有已证明的下一手三轮取将补偿。这不是整局胜率。
- 记录184、第174条命令前，红帅仅1血，黑车可在阵亡后由友军确定取帅。候选保留弃车的价值。
- 记录97、第76条命令前，末轮双方残血炮。候选的即时死子概率略升，不能忽略换血收益和后续取舍。

新增回归保留上述三例与按原记录顺序找到的首份新增确定反击案例；8份正常及换色查询、160个单元、50个确定反击单元通过。原0.6.140在新增检查中失败。最终入口的60个专项脚本及143项既有界面流程通过，原59份脚本及旧断言未改。

## 耗时和完整对照

耗时使用全部既有219状态，加预先指定的新增影响、将帅与末轮边界及三残局首末轮，共232份。每份首查一次、预热三次、原版与候选交替十次，串行、不采样分析、不删状态、不重测取最好值。原门槛为状态中位50毫秒、单次及首查100毫秒。

Node和Edge均通过。Node最高状态中位约9.57毫秒、最高热单次约12.35毫秒；Edge分别约5.1、6.2毫秒，全部计划与Node逐项匹配。Edge最终仅核对计算脚本；之后对建议补充的文字调整未改变计算脚本，没有重复性能测量。结果只代表本机。
