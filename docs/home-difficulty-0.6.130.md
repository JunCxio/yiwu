# 0.6.130 首页难度说明

首页原先只显示练习、标准两个名称，具体区别在较长的玩法说明中。现在选定难度后，原有模式说明区直接解释：练习电脑出招更随机，标准电脑比较武斗收益与将帅风险；生命、伤害不随难度改变。同机与教学显示难度不生效。

难度选择通过 `aria-describedby` 关联原有即时说明。模式、对战方式和难度沿用已有变化入口，不新增页面区域或布局规则。修改的是下一局设置，当前对局、继续本局的难度与已锁定暗招保留。

## 本轮诊断与取舍

从[0.6.129 培养核查](balance-0.6.129.md)的主批与追加复测中，取出25场练习快速局的单子实际输出胜局，按真实命令重放至原终态。检查33次守将被进攻入口，没有找到最后一步完全解除将帅威胁的空位移动或整备；更早的所查受攻行动也没有这类安全替代。没有检查交战救援或全部多步策略，不能据此认定败局不可避免。

另精确匹配原选择1,030次后，固定这33场武斗的入口及双方随机状态，仅将守将改用标准出招。当场守将阵亡由25次变为7次，23场剩余生命更多，2场更少。这是同入口的局部分支，不能当作整局胜率或全面更强的证明。

本轮保留练习的原有出招方式，也没有据此削弱培养牌。正式改动仅帮助玩家理解难度，不能宣称修复了将帅防守、培养平衡或长局。
