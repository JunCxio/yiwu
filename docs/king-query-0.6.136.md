## 改动与验证

CPU采样定位到将帅退路推演中的大量走法形状及支援计算。威胁评分只使用“是否存在来攻者”，现在找到第一个有效威胁就停止，不再收集全部来攻棋子。普通棋子、残局中黑将豁免、重复局面权重及支援分母保持。

将帅面对一血来攻者时，基础斩击面对任意合法招式至少反伤1点，首轮最多承受8点。因此将帅生命达到9时必有存活反杀，无需构造完整交战矩阵；两血以上来攻者及低血将帅继续按原判断。新增625项伤害边界、392项威胁参考对照，包含168项高血反杀；未来修改伤害或牌面时，这条边界检查必须继续通过。

132份完整走棋查询的2,970个行动评分及排序逐项相同，74份标准武斗计划相同，输入保持。32份原版控制重新执行的9,771条命令、7,241次棋盘选择和1,788轮武斗、逐子统计及完整终态相同。它们是旧输入复跑，不能算作新增平衡样本。

56个原有仓库脚本保持原断言通过。页脚先升级而导出版本号尚未升级时，143项界面流程中的版本一致性检查失败；已将导出元数据及文件名同步为0.6.136，最终入口143项通过。最终版另通过新增反杀边界检查。规则和电脑脚本与计时及回归使用的入口逐字一致，最后仅同步版本文字。
