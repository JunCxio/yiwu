# 0.6.107 兵卒目标方向复测：未采用

这次试验排除了兵卒身后敌子的接近收益，局部评分符合候选预期，但新起点自对弈明显变长，标准局和棋更多。因此不采用候选，正式游戏仍为0.6.107，入口、本机镜像、规则、界面、电脑策略和续局保持原字节。试验文件中的0.6.108仅为冻结候选标识，没有发布该版本。

## 问题与修改范围

以提交 `1d1a813929bcc81a0ca33068cd94a512169447bb` 为基线，完整重放已公开的[536场培养配牌矩阵](balance-0.6.107.md)、167,929条指令，终局哈希一致。在行动前已连续无伤至少20次的阶段，发现4,889次兵卒横移，其中3,655次最近敌子包含身后目标，43次同时靠近身后敌子、远离前方最近目标。

这只是静态方向核查。敌子可以移动，横移也可能承担避险、支援或炮架作用，不能把这43次全部认定为错误。20次无伤仅用于诊断分组，不是新增玩法阈值。

候选只让兵卒的最近敌子列表保留同排或前方目标：红兵 `q.y <= p.y`，黑卒 `q.y >= p.y`；没有前方目标时接近分为零，原有中央位置与推进分保留，车马炮不变。这与此前[0.6.87方向试验](pawn-direction-trial.md)的第二个候选采用相同筛选思路，本轮是在当前电脑和新随机根下复测，没有把旧结论当作当前版本的验证。

`position` 同时用于走棋排序和 `twoRoundCapturePlan` 的吃子后评分，后者影响标准武斗选招与提示。因此只能说武斗函数代码没有直接修改，不能说标准武斗行为不变；练习武斗分布保留，两种难度共用的走棋排序都会受影响。

## 局部检查与完整对照

从上述43次选择中，每模式保留前四个位置，共八个位置、来自七份历史记录。标准局第265次行动前，红兵已在底线 `(1,0)`，向 `(0,0)` 横移会靠近身后黑象并远离前方目标；对应评分约从 `+0.045` 变为 `-0.095`，候选标准电脑改为推荐移帅。完整历史、红黑旋转、两种难度合法性、没有前方目标时不虚增收益、保留前方目标和输入不变的检查通过。基线在具体排序断言失败，这验证了候选的局部目标，不证明整体策略更好。

最初14次试跑用于观察七份旧病例，随后冻结候选、输入、驱动和上限。最终记录包括13份旧病例各跑基线和候选，共26场；另两批新起点共64场。试跑不计入最终90场，也不增加独立样本数。

每批每模式四组配牌与随机序列根，分别使用默认／默认、分散／防守、集中／分散、混合／防守；每组运行双方基线、候选执红、候选执黑、双方候选四场。64场来自16组新根，32个新种子与已核对的1,024个旧种子无重合，同根四场彼此相关，不是64个独立起点，也不是完整培养矩阵。

| 新起点自对弈指标 | 快速：基线→候选 | 标准：基线→候选 |
|---|---|---|
| 平均棋盘行动 | 134→185 | 194.75→296.75 |
| 最长棋盘行动 | 301→457 | 333→496 |

候选换色直接对战，快速得9／16分、标准8／16分，没有证明整体更强。旧矩阵最长快速598步和棋变为286步和棋、最长标准602步和棋变为228步黑胜，但这些是挑出的旧病例，不能替代新起点结果。三条来自同根的红炮33步单子输出胜局和另一条旧黑车36步单子输出胜局均保留，不能宣称集中培养或单子主导得到解决。

全部90场自然结束，25,015条指令独立重放，配牌、预算、逐子实际损血、耗牌、阵亡、终局原因及状态哈希一致。13份旧基线的完整操作与已有公开记录精确复现。2,000次棋盘行动和14,000个内部步骤仅作保护，超限会报错，没有将测试上限计作和棋。
