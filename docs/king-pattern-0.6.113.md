# 0.6.113：临危将帅的混合应招

标准电脑会对最近两次同类出招增加应对偏好。这种偏好在将帅本轮可能被击倒时，也会加重单一招式，给对手留下较容易针对的选择。

本版在应用历史偏好前，核对己方将帅的合法选招与对手合法回应。只要存在本轮直接判负的组合，就保留原矩阵混合策略，跳过这次历史加权。原有确定胜局、安全选招、两轮避险与省牌检查保留。普通棋子、未出现这种败局组合的将帅继续参考历史。修改同时作用于标准电脑和标准选招建议，不读取已锁定的对手暗招。

练习电脑、走棋评分、规则、伤害、培养预算与卡牌数值、CSS、续局版本1均保留。旧存档中已锁定的暗招照原记录恢复，进入下一轮后才重新决策。

## 局部依据

两份合法历史中，守将分别在第36次行动第4轮、第39次行动第5轮遭遇危险。逐个枚举对手合法回应，并按自己的混合选招概率计算当轮判负概率；对手若选择其中最不利的一招，原策略分别为58.244%、57.127%，候选为35.760%、35.590%。这不是双方整局胜率，也不是对所有局面的全局保证。

新增测试覆盖两份危险历史、未临危将帅与普通棋子的历史偏好，以及红黑旋转，共8个状态。检查概率合法、危险病例的最大当轮判负概率低于40%、安全与普通病例保持原计划、重复查询不修改输入。旧版在危险病例断言处失败。此前20份现版完整记录另检查出5处计划变化，其中2处降低上述风险，3处该指标不变，没有发现该批次指标升高；该审查不是穷举。

## 完整对照

固定16组新根，覆盖快速、标准与默认、分散、防守集中、车马炮集中、混合集中配牌。每根运行原版双方、候选执红、候选执黑、候选双方，共64场；另有4份旧记录的8场控制，总计72场。32个新种子排除已检查的1,644个种子，其中256个来自本轮独立武斗诊断；旧控制及同根换色有关联。

16组新根的四种模型组合操作序列全部相同，两种模式直接对战均得8／16分。快速自弈平均275.125步，标准292.625步，新旧相同。没有证据说明整体强度、对局节奏或培养平衡改善。

旧36步单车胜局的前58条命令相同，首次差异为第36次行动第4轮，红方由架势改为斩击；改后为166步黑胜，获胜方有4枚棋子造成伤害。另3份318、355、601步记录操作及终局完全相同。延长一份败局不等于防守成功，不能据此宣称单子主导或长局已解决。

40个仓库脚本、31项规则、143项界面流程通过。Edge在1366×768、390×844检查标准新轮次、旧锁定暗招、练习新轮次共6条实际流程，均核对真实结算、刷新不重复操作、无横向溢出或控制台警告错误。
