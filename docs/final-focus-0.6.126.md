# 标准守方末轮蓄势修正

0.6.126减少标准电脑一类无收益的末轮基础蓄势。它只在真实结算逐项不劣时把该概率交给架势，保留独有判和、旧版已锁定暗招和玩家手动选择。本轮不宣称整体棋力、节奏或培养平衡改善。

## 来源与规则边界

对0.6.125的一场标准快速局核查发现：黑车没有培养牌，通过黑马牵制红帅退路，在第38次行动的六轮武斗中取胜。这不是集中培养导致强子的证明。八种只替换一次红方走棋的分支有六种转和、两种仍败，不能据事后结果统一奖励移帅或削弱车牌。

进一步检查该末轮守帅计划，发现基础蓄势仍占少量概率。前一批72份标准记录的172个末轮均有这部分概率，但没有实际抽中基础蓄势，因此不能把它认定为这些败局的实际原因。新回归夹具保存完整合法历史；在原版上，移除蓄势的断言先失败，修正后通过。

第六轮之后气势按规则归零。候选只在普通棋局的标准守方计划中，同时存在基础蓄势和架势时检查替代。对进攻方每种合法招式分别调用真实结算：

- 若改变终局，保留己方胜局和判和；允许避免确定败局，不用不确定后续替换原本可得的判和。
- 若双方都回到棋盘，要求存活棋子、位置、培养牌、耗牌、行动方和无伤计数相同；己方生命不减、对方生命不增，且当前完整局面重复计数不更高。
- 所有回应均符合时，只将基础蓄势的概率加到架势，其余招式概率保留。

这不等于架势面对所有招式都能存活。例如该38步病例中，架势面对破势仍会判负，基础蓄势在同一回应下也会判负；“不劣”不能写成“必存活”。新增测试初稿曾混淆这两者，已按真实结果修正测试断言，候选逻辑没有为通过该断言而改动。

进攻方、前五轮、练习电脑、残局和培养牌不套用此替代。查询不读暗招、不改输入；已保存的电脑招式由原续局校验恢复，不重新抽取。
